# ALX Oracle for Venues — B2B offer

## Базовый тариф

**Запуск: 9 900 ₽ один раз**  
**Обслуживание: 2 990 ₽ / месяц**

После оплаты запуска клиент получает отдельного Telegram-бота со своей версией Микс Оракула на общей платформе ALX.

## Что входит

- название заведения и фирменный wordmark;
- логотип;
- отдельный Telegram-бот клиента;
- контакты заведения в профиле;
- безлимитный Микс Оракул для гостей;
- избранное и история;
- профиль вкуса;
- Community Mixes для гостей заведения;
- технический хостинг;
- обновления общей платформы;
- базовая техническая поддержка.

В базовом пакете интерфейс, цветовая система, логика и набор стандартных функций одинаковы для всех заведений. Это позволяет запускать нового клиента быстро и без отдельной разработки.

## Что не входит

Индивидуальный редизайн, отдельная цветовая тема, новые функции, интеграция с POS/CRM/меню, собственный каталог табаков, админ-панель под конкретное заведение и эксклюзивные права на платформу считаются отдельно.

## Права и доступы

Клиент сохраняет права на свой Telegram-бот, название, логотип и собственный контент.

Исходный код платформы, GitHub, Cloudflare, серверная инфраструктура и права на ALX Oracle клиенту не передаются. Клиент получает право пользоваться брендированной версией сервиса на период оплаченного обслуживания.

Токен Telegram-бота хранится только как зашифрованный Cloudflare Secret и не размещается в GitHub.

## Срок запуска

Стандартный запуск — после получения данных клиента и настройки Telegram-бота. Целевой внутренний норматив: **до 1 рабочего дня** без нестандартных доработок.

## Если обслуживание прекращено

После окончания оплаченного периода доступ брендированной Mini App может быть приостановлен. Telegram-бот остаётся у владельца заведения. Клиент может в любой момент перевыпустить токен через BotFather.

## Данные для старта

Нужно получить:

- название заведения;
- логотип PNG/SVG или публичную ссылку;
- username созданного Telegram-бота;
- токен бота для защищённого подключения к backend;
- Telegram заведения;
- телефон — по желанию;
- сайт / Instagram / VK — по желанию.

Не просить клиента присылать токен в публичные чаты и не помещать токены в GitHub.
